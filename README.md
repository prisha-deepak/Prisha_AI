# AI MR Release Intelligence

Local-first release intelligence app for analyzing merge requests, generating release-impact summaries, comparing releases, exporting release notes, and asking release questions through an LLM-backed assistant.

## What It Does

- Imports fixture-based merge request data.
- Stores repositories, merge requests, file changes, releases, and analysis in SQLite.
- Uses an LLM provider to generate structured MR impact analysis.
- Uses an LLM provider to generate release-note style AI descriptions.
- Uses an LLM-backed chat assistant over stored release/MR analysis.
- Lets users review releases, compare releases, and export release notes to Excel.

## Stack

- npm workspaces monorepo
- API: Node.js, Express, TypeScript, Prisma, SQLite
- Web: React, Vite, TypeScript
- Shared: TypeScript types
- LLM provider: OCI GenAI by default, with OpenAI fallback support in the backend AI abstraction

## Project Structure


Key backend areas:

- `apps/api/src/services/processing/processingPipeline.ts`
- `apps/api/src/services/ai/`

## Prerequisites

- Node.js 20 or newer
- npm
- OCI config file if using OCI GenAI, usually at:

```text
C:\Users\<your-user>\.oci\config
```

Copy or edit:

```text

```

```env
OPENAI_CHAT_MODEL=
```

## Install

From the repo root:

```bash
npm install
```

## Database

Apply Prisma migrations:

```bash
npm run db:migrate
```

The default database is SQLite at:

```text
apps/api/prisma/dev.db
```

## Run Locally

Start API and web together:

```bash
npm run dev
```

Or start them separately:

```bash
npm run dev:api
npm run dev:web
```

Default URLs:

- API: `http://localhost:4000`
- Web: `http://localhost:5173`

## Useful Test Commands

Health check:

```powershell
Invoke-RestMethod http://localhost:4000/api/health
```

Import demo SCM fixture:

```powershell
Invoke-RestMethod -Method Post http://localhost:4000/api/dev/import-fixture/scm
```

Import demo HCM fixture:

```powershell
Invoke-RestMethod -Method Post http://localhost:4000/api/dev/import-fixture/hcm
```

Ask the LLM-backed release assistant:

```powershell
Invoke-RestMethod -Method Post http://localhost:4000/api/chat `
  -ContentType "application/json" `
  -Body '{"question":"What changed in SCM?"}'
```

## Frontend Workflow

Open:

```text
http://localhost:5173
```

Main pages:

- Impact Analyzer: compare releases and use the release assistant.
- Releases: view release contents, AI descriptions, impacted modules, and export Excel release notes.

If the Releases page looks empty, select a release with merge requests, such as `Release_2026_01`, from the left release list.

## Build

Build all workspaces:

```bash
npm run build
```

## Notes

- LLM calls happen during fixture import/reprocess for MR impact analysis and AI descriptions.
- Chat calls the LLM live through the backend `/api/chat` route.
- Release comparison is deterministic and compares stored release/MR analysis.
- Release export uses stored analysis and should continue to work even though the analysis is generated by the LLM.
